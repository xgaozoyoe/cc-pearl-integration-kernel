Final code changes:
Copy addresses use32-bit regional offsets and fixed stride instead of repeated row/column/swizzle computation. Fixed3 A rounds and2 B rounds. For M divisible by256 all A rows are valid, so remove A bounds checks/source clamping; partial M falls back to the bounds-checked copywalk path. B bounds/zero fill remain intact. Opt-in library rejects R!=128 and dimensions>1048576 before its32-bit offset path.
Unchanged: CTA256x192,warp64x64,384threads/12warps,K64,2stages,64IMMA+16LDSM per warp/K64,operand reuse,transcript,PoW,V3,target,proof.
Final168registers,69632shared bytes,1CTA/SM,12resident warps,0spills/local bytes. Rejected3stage167registers/98304shared/1CTA/0spill; no occupancy improvement.
Static SASS whole-kernel instructions original928 -> copywalk896 -> final888. These are static counts, not dynamic issue density or elapsed Tensor Active.
