Current A-stream transcript ablation, GPU0,2026-10-08.

Purpose: remeasure the old ~7% transcript cost on the current candidate,without
production changes. Same CTA256x192,12warps,warp64x64,K64,two stages,R128,K4096.
All cases use64 static IMMA/16 LDSM sites in the K loop. Dynamic shared allocation
remains69632 bytes and one CTA/SM. Full/pure control168registers;local/redux167.
All tested variants have zero stack/spills. GPU clocks/power not changed or locked.

v0: unmodified A-stream full transcript.
v1: same compiled kernel as v4,enable_fold=0; skip all boundary transcript work
and final transcript output; consume all final C registers in one checksum/lane.
v4: same compiled kernel as v1,enable_fold=1; exact full transcript output.
v2: local per-lane eight-word XOR at all boundaries,checksum sink instead of state.
v3: local XOR plus warp REDUX at all boundaries,checksum sink instead of state.
The v2/v3 sink rotates and XORs each observation into a lane register. This adds a
serial dependency and is NOT equivalent to simply removing later transcript work.

The first compiled-out pure variant spilled44 bytes (48byte stack) and was NOT
benchmarked. A shorter final sink also spilled. The final runtime-gated control
avoids that spill and uses an identical machine kernel in v1/v4. The gate is at
SASS0x10a0 (enabled parameter c[0x0][0x188]);0x1790 skips fold;0x29e0 selects output.
This is an execution ablation,not a claim that transcript instructions disappear
from the binary. Final checksum overhead and mode branches remain in v1.

Correctness: both seeds42/1234 at256x384; all diagnostic outputs checked against
CPU int32 accumulation at each128K boundary and explicit lane ownership. v0/v4
transcripts match the accepted library. Both full variants additionally match all
transcript words at8192x8192. No real mining by diagnostic modes.

full-grid delta24.0167ms=7.814%. Unmodified v0 vs disabled v1 gives7.751% kernel
and7.273% full-grid reduction,with the caveat those kernels differ. v4 costs about
0.68% more kernel time than v0,so the gate control itself is small but nonzero.

The ~7% opportunity persists. However,local/redux proxy cases are slower than full:
extra sink dependency and compiled scheduling prevent a clean additive split.
