Partial register transcript state experiment, GPU0,2026-10-08.

Historical audit: tests/fold_ops.cuh Mode4/5/11 distributes one boundary result
per lane using lane==rb; it is the older CuTe path. The current hand-written
Ada rank128 generator tools/build_ada_rank.py explicitly implements rb%16,
rotate13 and shared-state updates. This establishes different code paths,not a
historical measured reason why the old register experiment was not retained.
Do not treat old R256/CuTe lane-state results as current R128 A-stream results.

Implementation: keep last1 or last2 of16 tiles/warp in one lane register.
For two tiles:lane0..15 owns all16words of tile14;lane16..31 owns tile15.
Owner=(tile-selected_start)*16+rb%16. First boundary pass assigns;second rotates
and XORs. Publish state into existing shared transcript once after K loop,before
existing CTA barrier and coalesced output. One-tile mode uses only lanes0..15.
All GEMM accumulator values stay in registers. No new shared layout or CTA change.

Second build replaces owner-conditional assignment with pure nonvolatile PTX
selp,computes rotl13(state)^x on every update (first state is zero),and selects
old/new state by owner. This is bit-equivalent but does not remove the compiled
mixed-path reconvergence. No volatile used for pure register operations.

Both builds:baseline168regs,tail1=167,tail2=168;384threads,69632Bshared,1CTA/SM,
zero stack/spills. All have64IMMA/16LDSM static main-loop sites. Fold LDS sites
16->15/14 confirms selected old shared loads are eliminated. Static BSSY sites
1->4/3 in both builds; total instructions880->896/888. Count includes final
publication where applicable; these are static counts,not dynamic cycle costs.

Conclusion: these four partial-register implementations do not improve performance.
Throughput loss~4-5% despite zero spilling and actual elimination of shared state
loads. Mixed ownership changes control flow and instruction scheduling; SASS
confirms extra reconvergence, but no new counter capture isolates its exact cost.
No claim that register storage intrinsically loses,or that an entirely different
full-register mapping cannot win. Do not expand this particular approach based
on these results. Existing A-stream and live-mining libraries retained unchanged.
