Late transcript shared-state prefetch, GPU0 only,2026-10-08.

Two isolated builds, each baseline plus last1/last2 tile-state preloads per warp.
First build uses conditional branch and explicit shared loads before all REDUX.
Second uses predicated ld.shared PTX, avoiding the added branch/reconvergence.
Only real shared-memory reads use volatile; no pure XOR asm was introduced.
Predicated load output uses early-clobber because initialization precedes addr use.
Both forms read old state only in lane0 and rb>=16; initial transcript writes
and all current-mainnet state semantics are unchanged.

SASS confirms intended loads before first REDUX in all four candidates. Native
64IMMA/16LDSM sites unchanged. First build adds a BSSY/BSYNC pair (2vs1); second
retains1. Static instruction slots880 baseline,904 branch form,888 predicated.
Registers baseline168,last1=167,last2=168;384threads,69632Bshared,1CTA/SM,zero
stack/spills. Instruction count equality does not mean identical main-loop schedule.
