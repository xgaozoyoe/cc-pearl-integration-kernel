Findings:
- early is byte-for-byte identical SASS to control, including instruction control encoding.
- two_ahead/compact do not move the three immediate first-half B load-consumer edges.
- paired changes real B use order and increases some load-to-use distances, but introduces40B stack,40B spill stores,48B spill loads (ptxas static counts, not runtime traffic).
- All kernels retain64 static IMMA and16 LDSM. Control matches validated lean-toggle SASS.
- Transcript and PoW digest match reference for full8192 region and edge shapes; racecheck/memcheck/synccheck pass on edge suite.
- No production replacement. Negative timing does not prove real B prefetch intrinsically ineffective; compiler scheduling and spill costs are confounders.
- Fixed-base-clock optional profile: sudo bash tools/profile_handoff_pairb.sh
